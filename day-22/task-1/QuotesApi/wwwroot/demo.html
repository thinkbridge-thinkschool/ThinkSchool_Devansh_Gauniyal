Resilience with Polly

Day 22 Task 1 — two dependencies, each with their own fault-injection switch (TEST/DEMO SCAFFOLDING, not production code — see README.md). The external service gets the full pipeline (bulkhead → retry → circuit breaker → timeout); Redis gets bulkhead → circuit breaker → timeout, deliberately no retry.

Walkthrough: drive a breaker from closed to open to half-open to closed
  1. Pick a dependency below and click Failing.
  2. Click Fire N requests a couple of times (N ≥ 10) — watch the breaker state pill turn Open and the outcomes shift to short-circuited.
  3. Wait ~10 seconds (the configured break duration) without clicking anything.
  4. Click Healthy, then Fire N requests once more — the state pill passes through HalfOpen for the first probe, then settles back to Closed once it succeeds.
Click Refresh state any time to see the breakers' current state without firing a request.
